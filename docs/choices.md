# Choices
"A reflection on your design choices and what you learned from undertaking the project."
---
I wouldn't say there were too many significant design choices to be made; the most notable one is the difference between toggling a button and changing its text vs hiding and unhiding pairs of buttons. Both methods were used, determined by how the listener called functions should change with the button.

most of the components of this project were things I was already able to do, though it did definately increase my familiarity with the function options within .addEventListener.
Calling bootstrap functions was something new, as was learning how to prevent SQL injection attacks, though I can see the current method becoming a bit more difficult when including larger message options where you dont want to just block special characters, and has routes around it.
